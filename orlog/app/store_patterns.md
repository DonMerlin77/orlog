- PATTERN [Layered Knowledge Architecture]: Structure agent expertise in three composable layers (curated core, auto-synthesized, learned) that can be independently maintained and versioned. Use this when building agents that need stable domain rules but must also adapt from new sources and user feedback without re-engineering the entire system prompt.
- PATTERN [Automatic Cache Invalidation via Content Hash]: Track combined modification times of multiple source files and use them as cache keys instead of explicit invalidation. - PATTERN [Optional Reasoning Lens Injection]: Provide a switchable second brain (reasoning framework) that experts hand-write once, then inject only into high-stakes agent paths (council, deliberation) via a boolean flag. This prevents prompt bloat for simple agents while ensuring critical decisions use the same mental models across the system.
- PATTERN [Graceful Fallback for Missing Domain Files]: Return empty strings or empty lists when optional brain files don't exist, rather than crashing or logging errors. This allows agents to bootstrap and function with minimal configuration, deferring expertise-loading until brains are available.
