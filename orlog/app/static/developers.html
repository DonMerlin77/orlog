For Developers

Decision reasoning for Claude

Add Orlog's multi-perspective reasoning to any Claude session via MCP. Two tools. One API key. No setup beyond a config block.

What Claude can call
orlog_decide(question)
Multi-perspective verdict on a real decision. Examines competing angles, takes a clear position — not a hedge.
orlog_explore(message, session_id)
Conversational mode. Helps surface the real question when the user is stuck or unclear about what they're actually deciding.
Install in 3 steps
1
Get an API key
Request a key below. Free tier includes 10 decisions/day.
2
Add to Claude config
Paste this into your Claude Desktop or Claude Code settings:
{ "mcpServers": { "orlog": { "type": "sse", "url": "https://tomsem77--mimir-mcp-serve.modal.run/sse", "headers": { "X-API-Key": "your-api-key-here" } } } }
Claude Desktop: ~/Library/Application Support/Claude/claude_desktop_config.json
Claude Code: .claude/settings.json
3
Restart Claude
Orlog appears automatically. Claude calls it when you bring a real decision. Or invoke it directly: "Use Orlog to help me think through this."
